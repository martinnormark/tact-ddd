Tutorials are **learning-oriented** -- they guide you through building something real, step by step, using multiple packages together. Each tutorial assumes you have tact-ddd installed and basic TypeScript knowledge.

If you are looking for quick answers to specific tasks, see the [Guides](/docs/guides) section instead.

## Prerequisites

All tutorials assume:

- TypeScript 5+ with strict mode enabled
- Bun or Node.js 18+ as runtime
- `@tact-ddd/core`, `@tact-ddd/events`, and `@tact-ddd/ids` installed

Individual tutorials list any additional requirements.
