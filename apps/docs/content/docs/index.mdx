Tactical DDD building blocks for TypeScript -- entities, value objects, aggregate roots, domain events, typed IDs, and the transactional outbox pattern.

<Cards>
  <Card title="@tact-ddd/core" href="/docs/reference/core">

  </Card>
  <Card title="@tact-ddd/events" href="/docs/reference/events">

  </Card>
  <Card title="@tact-ddd/ids" href="/docs/reference/ids">

  </Card>
  <Card title="@tact-ddd/outbox" href="/docs/reference/outbox">
    Transactional outbox pattern with ports and adapters
  </Card>

## Quick install

```sh
bun add @tact-ddd/core @tact-ddd/events @tact-ddd/ids
```

Or install only the packages you need -- they are independently usable and have minimal dependencies.
