---
title: "@tact-ddd/outbox"
description: Transactional outbox pattern with ports and adapters
---

The outbox package implements the transactional outbox pattern. It defines port interfaces (`OutboxStore`, `OutboxSerializer`) that you implement for your infrastructure, and provides a concrete `OutboxProcessor` that processes pending messages.

```sh
bun add @tact-ddd/outbox @tact-ddd/events
```

## Peer dependency

This package requires `@tact-ddd/events` ^0.1.0 as a peer dependency. It uses `IntegrationEvent` and `IntegrationEventBus` from that package.
